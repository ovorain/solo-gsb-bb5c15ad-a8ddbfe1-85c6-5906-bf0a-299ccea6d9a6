# 字幕校稿对齐工具

粘贴**逐行对白稿**与 **SRT 字幕**，自动求最低代价的全局单调对齐，并排展示对位、缺项与时间码，并可下载含状态的 CSV 结果。

## 一键启动（Docker Compose）

```bash
docker compose up --build
```

启动后在浏览器打开：

```
http://localhost:8000
```

依赖（FastAPI、Uvicorn、python-Levenshtein）会在镜像构建时自动安装，无需本地准备环境。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 端口映射 | `8000:8000` | 在 `docker-compose.yml` 的 `ports` 中修改，如改为 `"9000:8000"` 后访问 `http://localhost:9000` |
| 跳过代价 | `0.45` | 页面工具栏可临时调整（跳过任一侧一条的代价，取值 0~1） |
| 单侧条目上限 | `4000` | `app/main.py` 中的 `MAX_ITEMS`，防止对齐矩阵过大 |

## 本地开发（不用 Docker）

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

## 算法说明

1. **解析**：对白稿按行切分（空行忽略）；SRT 按空行分块，保留每条的时间码与（可能多行的）原文，并剥离 `<i>` 等 HTML 标签与 `{\...}` ASS 标签。
2. **归一化**：NFKC 归一后去掉所有空白与标点（Unicode `P*`/`Z*`/`C*` 类别），英文字母转小写，仅用于匹配，不影响展示。
3. **代价模型**：
   - 两条匹配：归一化字符编辑距离 `Levenshtein(a, b) / max(len(a), len(b))`，取值 `[0, 1]`；
   - 跳过任一侧一条：固定 `0.45`。
4. **对齐**：Needleman-Wunsch 动态规划求**最低代价全局单调对齐**。两侧条目各最多匹配一次，允许缺项；由于对齐全局单调，重复短句会依整段顺序配对。利用「匹配代价超过 `2×跳过代价` 时最优解必然改用两次跳过」做下界剪枝，不改变最优结果。
5. **状态**：`匹配`（两侧对上）、`缺字幕`（剧本有条目而字幕缺项）、`缺剧本`（字幕有条目而剧本缺项，如广告、歌词）。

## CSV 字段

`序号, 状态, 剧本行号, 字幕序号, 剧本原文, 字幕原文, 开始时间, 结束时间, 匹配代价`

文件带 UTF-8 BOM，可直接用 Excel 打开。

## 接口

- `POST /api/align`：请求体 `{"script": "...", "srt": "...", "gap_cost": 0.45}`，返回对齐行与统计。
- `GET /api/health`：健康检查。
